# TKMNM Cargo website

One-page static site for TKMNM Cargo (Tkmnm Holdings LLC): air freight from New York to Ashgabat, Turkmenistan.

- `index.html` — the page
- `style.css` — styles
- `favicon.svg` — icon / logo mark

No build step and no external dependencies. Served by GitHub Pages from the `main` branch root.

## Custom domain

When the domain is ready: add a `CNAME` file containing the domain (e.g. `example.com`), point DNS at GitHub Pages, and set the domain under repo Settings → Pages.
