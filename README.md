# Tkmnm Holdings website

One-page static site for Tkmnm Holdings LLC: digital products for the transportation industry (YolTrans, El-Pochta, YallaMachines, VIN truck identifier, GPS tracking), web & AI services, and freight & freight forwarding.

- `index.html` — the page
- `style.css` — styles
- `favicon.svg` — icon / logo mark

No build step and no external dependencies. Served by GitHub Pages from the `main` branch root.

## Custom domain

When the domain is ready: add a `CNAME` file containing the domain (e.g. `example.com`), point DNS at GitHub Pages, and set the domain under repo Settings → Pages.
